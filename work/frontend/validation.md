# Проверка фронтенда

25.10.2026. Ветка `feat/hotel-frontend`, база `adb6014`.

- Backend: 147 unit/contract tests passed в изолированной среде Python.
- Frontend: `npm run verify`: 36 rules, typecheck, Biome, 309 tests, production build passed.
- npm audit после обновления undici: 0 vulnerabilities.
- Проверка Chromium и axe: оба языка, обе темы, главная, кабинет отельера,
  сравнение и неизвестный маршрут. Production-сборка: 10 passed (7.5s), включая длинные данные на 375px.
- Контрактные сценарии: повтор одинакового поиска, источник и GeoJSON, WebGL canvas,
  мобильный фокус, сравнение двух отелей, ответ/подтверждение/исправление.

Реальные вызовы `/health` и `/characteristics` идут на бэкенд. Остальные успешные
ответы существуют только в тестах. Проверка не подтверждает серверную реализацию
поиска, хранилища отелей, terrain, прав отельера или доступности номеров.

Исправления по ревью: повтор одинакового запроса сбрасывает соответствующий query;
мобильный выбор переносит фокус в сведения об отеле. MapLibre v6 требует явного
URL worker в Vite: подключён локальный `?worker&url` по
[официальной инструкции](https://maplibre.org/maplibre-gl-js/docs/).
Регрессионная проверка требует видимый WebGL canvas и отсутствие сообщения об ошибке карты.

Для внешних доказательств разрешены HTTP(S)-ссылки `<a>`; загрузка внешних
картинок, шрифтов и скриптов по-прежнему запрещена проверкой remote-assets.
Это исключение закреплено отдельным тестом проверки.

Ограничения сборки: предупреждение о размере chunk с MapLibre и предупреждение
PostCSS про параметр `from`; сборка успешна. Оптимизация разделения картографического
кода возможна после измерения на целевом устройстве.
