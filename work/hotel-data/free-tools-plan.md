# Бесплатные инструменты окружения и афиши

Задача: подключить полезные источники без платных ключей. Ветка feat/hotel-agent-mvp. Claude и запущенный стенд не запускать/не перезапускать.

Объём: KudaGo и публичная разметка Event для афиши; GBIF для исторических наблюдений; выборочные измерения ESA WorldCover 2021 для окружения; MET Norway для прогноза агента. Все вызовы по требованию, ограничены по времени, объёму, радиусу и количеству отелей. Никаких загрузок всей России при старте.

Интерфейс place_research: запрос около координат → числовые измерения либо записи с источниками. События сначала проходят проверку дат и площадки, затем смысловую проверку цитаты существующим механизмом evidence. Отсутствие данных не порождает отрицательный факт. Метрики окружения проходят measurement_scope.

Большие импорты Overture, развёртывание маршрутизатора и источники с непроверенными бесплатными условиями не входят в эту итерацию. Проверка: изолированные HTTP/raster фикстуры, агентный путь до факта и provenance, штатные backend checks. Живые бесплатные пробы только отдельно от тестов; без LLM.


Реализовано: четыре новых действия в схеме и диспетчере агента, MET в прогнозе агента и HTTP, provenance/цитаты/геометрия, смысловая и временная проверка событий, кеш MET и честная недоступность, ссылки в источниках карты. Проверки и живые бесплатные пробы записаны отдельно. Запущенный стенд и конфигурация LLM не изменялись.
