## Ограничения

В текущем контракте подтверждённая сумма дополнительной услуги известна только для pets_policy.fee_rub. free=false в списке поставщика не означает paid=true. Другие услуги остаются в перечне удобств без выдуманной цены и не включают платную вкладку. Для полного каталога платных услуг потребуется явное расширение API источником, суммой и периодом оплаты.

Работы отельера и ночной карты остаются в других worktree и ещё не объединены. Общий путь Tabs и две локализации требуют сохранения совместимых добавлений при слиянии; памятка — README.md в этой папке.
