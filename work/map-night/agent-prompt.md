## Правила кода

- Без комментариев и docstring. Файлы не длиннее 250 строк, модули с понятными именами, без
  `utils`/`helpers`. Код и тесты на английском, тексты интерфейса — через словари RU и EN.
- Неочевидные решения: формулу `grade()`, выбор лунного света и запасной «свет города»,
  разделение на поверхности и светящиеся элементы — запиши в `docs/design-decisions.md`.
- Контракт API и бэкенд не меняются. Дневной городок в 13:00 должен остаться прежним.
