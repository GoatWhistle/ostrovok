  лежат 1767 деревьев, 254 аллеи `natural=tree_row` и 26 519 POI; измерено через Overpass
  2026-10-28 (проверено повторно: `natural=tree` 1767, `tree_row` 258 в bbox).

- [Сигналы качества для рекомендации](../research/recommendation-signals-2026-10-28.md): восемь
  аспектных оценок гостей Островка, включая `wifi` 8.10, уже приходят в карточке и частично
  разбираются; отзывы и расширенные счётчики не читаются; у 101hotels разрешена страница отзывов с
  подоценкой «Качество сна» и тегами по корпусу; связки «отель → ИНН» бесплатно нет.
- [Контекст вокруг отеля](../research/context-signals-2026-10-28.md): Copernicus Marine по Чёрному
  морю читается анонимно (zarr, HTTP 200, 24 194 байта), волна 0,58 м и вода 20,2 °C на
  2026-10-28; у 22 из 103 пляжей Сочи заполнен `surface`, из них 19 `pebblestone` и 1 `sand`;
  ADS-B над Россией пуст по трём сетям, GTFS по Сочи не существует.

- Не проверено: общий стенд (`hotel-agent-db-1`) не миграцировался — база общая с другими

  слои `tree_rows` и `props` будут пустыми, а `pois.class` останется `default_poi`.
- Глазами интерфейс не смотрел: блок `declared_rooms` и аллеи на карте не сняты на 375/1440 в двух
  темах и двух языках.

## Ограничения, записанные в код и документацию

- `views` — заявление поставщика, не измеренная линия обзора; название категории засчитывается
  только при слове вида, поэтому «люкс Морской» остаётся без кода.
- Фотографии номеров с Alean не берутся: на проверенной карточке две разные категории коттеджей
  отдавали один первый кадр галереи.
- `occupancy` и `bed_places` — параметры тарифа, а не максимальная вместимость категории.
- `declared_rooms` не сливаются с `room_groups`: сопоставление категорий двух поставщиков по
  названию не делается.
