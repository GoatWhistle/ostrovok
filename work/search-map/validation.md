# Поиск на карте: проверка 2026-10-28

Реализовано: карта вместо панели этапов, дневное оформление во время поиска, один переход
к реальной области, кандидаты из SSE с кластеризацией, итоговые состояния прежних маркеров,
вопрос о городе, повтор после ошибки, отмена устаревшего запроса. Автоматических маршрутов
нет: доступны прежние маршруты фактов с полученной геометрией. Проценты не вычисляются.
Произвольные предложения городов удалены, уточнение вводится в чате.

Проверено:
- Node 24 из локального контейнера: `npm run verify`, 119 файлов тестов, 632 проверки,
  rules/typecheck/lint/test/build успешно. Предупреждения линтера и размера bundle остаются.
- Backend: Ruff и mypy (586 файлов), 1114 unit/contract-тестов успешно.
- Реальный dev API с FakeLLM и существующим PostGIS: отсутствие города, ответ «Сочи»,
  уточнение с городом из контекста, отдельный запрос Москвы. `api-scenarios.json` сохраняет
  разборы. Исходное пожелание сохраняется в normalized_query; внутренние ключи намерений
  могут меняться существующим исследователем.
- Chromium/SwiftShader, RU, 1440×900 и 375×900, тёмная тема: реальная выдача кандидатов,
  дневной вид, возврат neon (localStorage сохраняет neon), пустой ответ, отсутствие pageerror.
  Кадры `search-1440.png`, `search-375.png`, `result-1440.png`, `result-375.png`.
  Для съёмки тестовый браузер замедляет доставку настоящих SSE-кадров, данные не подменяются.
- Unit-тесты: вопрос без города, реальная рамка, пустой ответ, ошибка геокодирования/поиска,
  запрет использования прежней области при новом запросе, отмена первого запроса вторым,
  игнорирование позднего ответа при уходе в историю/на главную. RU/EN проверены словарными тестами.

Границы: автономный парсер имеет собственный ограниченный список распознаваемых мест;
Казань им не распознаётся. Механизм карты не содержит городских координат или списка городов.
Платный LLM не запускался. EN/светлая тема дополнительно снята на 1440 px с обычным движением и на 375 px с reduced motion.
Мобильная съёмка с обычным движением пропустила краткий этап checking и завершилась timeout;
данный прогон не засчитан. Измерение движения на реальном GPU не выполнено; производительность SwiftShader не считается результатом.
Действующий Compose не пересобирался. Для релиза требуется совместная сборка API и frontend.

Сопутствующие исходные блокеры verify: превышение длины map-layers.ts (убраны пустые строки),
сложность HotelComparison (вынесена проверка диапазона количества отелей), root-владелец dist
(восстановлен владелец только генерируемого каталога). Тексты и поведение сравнения не менялись.
