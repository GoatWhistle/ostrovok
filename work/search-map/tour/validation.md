# Проверка плавного поиска, 2026-10-28

Реализовано: плавный полёт 2,4 с; смена кандидата каждые 4,2 с только во время поиска;
прорисовка настоящего маршрута после прилёта; немедленный переход к победителю. Панорамирование
пользователем отключает автополёт до следующего запроса. Reduced motion не перебирает отели.
Маршрут и точки поверх 3D-зданий остаются видимыми. Пояснение о более длинном пути появляется
только если другой рассчитанный пеший путь действительно короче.

Выбор: лучший уровень соответствия пожеланиям, затем кратчайший доступный пеший путь к первому
положительному nearby-условию. Если пешего графа нет, расстояние явно подписано как прямое.
Без маршрута камера уточняет выбор по доступному рейтингу среди лучших возвращённых результатов,
используя те же запросы карточек. Отсутствующий рейтинг не заменяется звёздами.

Проверки:
- Бэкенд: ruff, mypy (589 файлов), 1118 unit/contract тестов прошли. После оптимизации выборки
  повторно проверены затронутые сценарии.
- Фронтенд: Node 24, 36 правил, типы, линтер, 635 тестов прошли; сборка выполнена.
- Реальная БД PostGIS, фиксированный тестовый разбор «рядом с баром», реальный маршрутизатор:
  итоговый прогон 4,241574 с. 7 рассчитанных сцен, победитель «Моё море», 31,9 м, mode=graph;
  он же первый результат. Живую платную LLM не вызывали, её задержка в это число не входит.
- Chromium SwiftShader, 1440 px с обычной анимацией, 375 px с reduced motion: ошибок JS нет,
  сцена победителя корректна. Кадры route-*.png и winner-*.png рядом.
- Для кадров воспроизводится фактический записанный SSE с искусственной задержкой между
  событиями только в браузерном инструменте `capture.cjs`. Продукт выдачу не задерживает.
- После визуальной проверки добавлен SVG-слой поверх крыш; на 375 px он проверен кадром.
  Производительность реальной GPU не измерялась. Часть рейтингов может отсутствовать у поставщика.

Ночная карта остаётся на паузе. Второго коммита по ней нет; пуш не выполняется.
