# Бесплатные источники погоды, климата, воздуха и маршрутов

Дата проверки: 2026-10-26. Только исследование официальных документов; новые API не подключены,
запросы с ключами, регистрация, платные вызовы, загрузка национальных наборов и запуск стенда
не выполнялись. Бесплатная внешняя услуга не отменяет расход диска/CPU собственного сервера.

## MET Norway: прогноз без оплаты за запросы, включая коммерческое использование

Полезен для пожеланий «не жарче 25 градусов на даты поездки», «мало ветра», «без дождя».
Публичный Locationforecast охватывает весь мир. Для основной части мира горизонт до десяти
дней и сетка приблизительно 9 км; микроклимат конкретного фасада он не измеряет.
[Модель и география](https://docs.api.met.no/doc/locationforecast/datamodel.html).

Метод: `GET https://api.met.no/weatherapi/locationforecast/2.0/compact?lat=<lat>&lon=<lon>&altitude=<metres>`.
Параметры и пример формата: [официальный старт](https://docs.api.met.no/doc/GettingStarted).
Отдельный платёжный/API-ключ для этого интерфейса не нужен; для запроса требуется настоящий
идентифицирующий User-Agent с названием приложения и контактной страницей/почтой.
Бесплатное коммерческое использование прямо подтверждено в
[FAQ](https://docs.api.met.no/doc/FAQ.html); данные лицензированы NLOD 2.0 / CC BY 4.0 с атрибуцией
MET Norway ([лицензия](https://docs.api.met.no/doc/License.html)).

Нужны кеш по `Expires`, условные запросы и остановка/ожидание при 429; SLA нет.
Не подставлять чужие или выдуманные контакты. [Правила сервиса](https://docs.api.met.no/doc/TermsOfService.html).
Бесплатность сервиса не означает право создавать неограниченный поток запросов.

**Рекомендация:** первый кандидат на дополнительный погодный адаптер для бесплатного продукта.
Это вывод из условий и интерфейса, а не результат теста доступности или качества в России.
Oceanforecast того же поставщика рассчитан на Северо-Западную Европу и не является заменой
морского прогноза для всей России ([список продуктов](https://api.met.no/)).

## NASA POWER: климатические пожелания, а не прогноз конкретного номера

Полезен для «солнечнее в октябре», «обычно не жарко летом», «меньше осадков в сезон».
Официальный проект предоставляет бесплатные глобальные климатические данные через REST API.
Метеорологическая сетка порядка 0,5×0,625°, солнечная — 1×1°: для сравнения регионов,
не двух соседних отелей. История/климатология не доказывает погоду будущей конкретной даты.
[Описание и разрешение](https://power.larc.nasa.gov/docs/tutorials/service-data-request/api/).

Пример шаблона, не выполненный запрос:

```text
https://power.larc.nasa.gov/api/temporal/daily/point?parameters=T2M,PRECTOTCORR,ALLSKY_SFC_SW_DWN&community=RE&longitude=<lon>&latitude=<lat>&start=<YYYYMMDD>&end=<YYYYMMDD>&format=JSON
```

Дневной точечный метод принимает до двадцати параметров. Следует кешировать ячейки и периоды,
а не повторять один климатический запрос на каждый отель. Возможен HTTP 429.
[Daily API](https://power.larc.nasa.gov/docs/services/api/temporal/daily/),
[общая документация](https://power.larc.nasa.gov/docs/services/api/).
Не переносить на этот endpoint лимиты `api.nasa.gov`: это другой сервис.

## OpenAQ v3: измерения загрязнения с бесплатным ключом и квотой

Помогает искать районы с меньшими измеренными PM2.5/PM10 на заданный период.
`GET https://api.openaq.org/v3/locations?coordinates=<lat>,<lon>&radius=<m>` выбирает станции;
параметр `radius` ограничен 25 км. Далее нужны sensors и measurements, даты, единицы и расстояние
до станции. [Метод locations](https://docs.openaq.org/api/operations/locations_get_v3_locations_get).

Требуется бесплатная регистрация и `X-API-Key`; текущая квота 60 запросов/минуту и
2000/час. Превышение возвращает 429; повышение лимита предлагается отдельно за оплату,
автоматически его не подключать. [Ключ](https://docs.openaq.org/using-the-api/api-key),
[лимиты](https://docs.openaq.org/using-the-api/rate-limits).
Доступ к API не отменяет лицензии исходных поставщиков; выбирать только совместимые записи
и сохранять атрибуцию. Нельзя собирать данные в обход официальных интерфейсов.
[Условия](https://docs.openaq.org/about/terms).

Открытый каталог не включает все станции мира и не обещает покрытие каждого российского города.
[Границы данных](https://docs.openaq.org/about/about). Ближайшая станция не измеряет воздух
внутри гостиницы. Это не основание обещать отсутствие аллергенов или безопасность для здоровья.
**Рекомендация:** после проверки числа пригодных станций России и их актуальности.

## Valhalla: бесплатный расчёт маршрута на собственном OSM-графе

Это вычислительный инструмент, а не независимый источник новых POI. Полезен для
«10 минут пешком до моря», «до вокзала без лестниц», «велодорожка рядом».
Есть route, matrix и isochrone; пешеходный и велосипедный режимы, режим wheelchair,
учёт части ограничений доступа. Для общественного транспорта необходимы отдельные GTFS;
наличие дороги или остановки не даёт расписание.
[Сервисы](https://valhalla.github.io/valhalla/api/),
[параметры маршрута](https://valhalla.github.io/valhalla/api/route/api-reference/).

При локальном запуске маршрут вызывается через `/route`, матрица — `/sources_to_targets`,
зоны достижимости — `/isochrone`. Публичный demo endpoint не предлагается как неограниченный
бесплатный production API. Лицензия движка MIT; лицензия исходного OSM-графа и атрибуция
сохраняются отдельно. [Официальный репозиторий и лицензия](https://github.com/valhalla/valhalla).

В проекте уже есть собственный пешеходный граф/расчёт для среза Сочи; полезность Valhalla —
проверить вариант распространения маршрутов на другие регионы и режимы, без замены работающего
кода по одному совпадению названия. Время расчётное, без гарантии фактической скорости человека,
работающих лифтов или полной доступности при неполных OSM-тегах.

## Условно бесплатные или спорные альтернативы

**Open-Meteo** уже используется для обычного прогноза, но новые направления Marine/Air Quality
пока не подключены. Marine предоставляет высоту волн, температуру поверхности моря и течения;
Air Quality — модельные загрязнители, пыль и ограниченные европейские пыльцевые поля.
[Marine](https://open-meteo.com/en/docs/marine-weather-api),
[Air Quality](https://open-meteo.com/en/docs/air-quality-api).
Бесплатный hosted API разрешён для некоммерческого использования; это отдельно от открытой
лицензии данных. Для коммерческого продукта не считать его безусловно бесплатным.
[Условия](https://open-meteo.com/en/terms). Погодная ячейка моря не подтверждает условия
конкретного пляжа, а поле пыльцы не означает полное покрытие России.

**Meteostat** даёт исторические станционные данные без ключа: годовые CSV станции
`https://data.meteostat.net/hourly/{year}/{station}.csv.gz`, глобальный годовой Parquet
`https://data.meteostat.net/hourly/{year}.parquet`, каталог `https://data.meteostat.net/stations.db`.
[CSV](https://dev.meteostat.net/data/timeseries/hourly),
[Parquet](https://dev.meteostat.net/data/bulk/hourly),
[станции](https://dev.meteostat.net/data/weather-stations).
Есть заполнение пропусков моделями: не называть весь ряд измерениями станции.
Документация разработчика указывает CC BY 4.0, а пользовательский support — CC BY-NC 4.0.
До устранения противоречия не предлагать как безусловно свободный коммерческий источник.
[Лицензия разработчика](https://dev.meteostat.net/license),
[противоречащая страница поддержки](https://meteostat.net/en/support).

## Что проверить перед подключением

Для любого кандидата сначала небольшой фиксированный набор городов/дат и реальных ответов:
доступность из среды, отсутствие платежной настройки, смысл единиц, разрешение сетки и диапазон
дат. Затем кеш и ограничения нагрузки, отрицательные/пустые ответы, атрибуция и конкретные
примеры пожеланий. Такое подключение и проверка России в этой исследовательской задаче не выполнялись.
