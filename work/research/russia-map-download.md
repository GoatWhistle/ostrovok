# Полный OSM-экстракт России: размер и время загрузки

Проверено 2026-10-25 по [официальной странице Geofabrik](https://download.geofabrik.de/russia.html) и HTTP `HEAD` самого файла.

- Geofabrik публикует единый [`russia-latest.osm.pbf`](https://download.geofabrik.de/russia-latest.osm.pbf) со всей Россией. На момент проверки ссылка перенаправляла на `russia-261024.osm.pbf`, `Last-Modified: 2026-10-24 22:32:03 GMT`, `Content-Length: 4 187 472 293` байта (3,90 ГиБ / 4,19 ГБ). Диапазонные запросы разрешены (`Accept-Ranges: bytes`), поэтому прерванную загрузку можно продолжить.
- [Региональные PBF](https://download.geofabrik.de/russia.html) доступны по федеральным округам; их публично показанные размеры: Центральный 841 МБ, Крымский 38,8 МБ, Дальневосточный 375 МБ, Северо-Кавказский 123 МБ, Северо-Западный 625 МБ, Сибирский 560 МБ, Южный 301 МБ, Уральский 378 МБ, Приволжский 740 МБ. Для одной копии страны проще единый файл.
- Страница Geofabrik указывает дату данных в файле `2026-10-24T20:20:51Z` и предоставляет [файлы изменений](https://download.geofabrik.de/russia-updates/) для последующих обновлений. На странице указана лицензия OpenStreetMap ODbL 1.0.
- Это исходные объекты OpenStreetMap в PBF, не готовая отрисованная карта и не цифровая модель рельефа. Для поиска по всей России потребуются отдельные индекс и база данных; их итоговый размер и время импорта данным HEAD-запросом не определяются.

Теоретический минимум передачи 4,187 ГБ без накладных расходов: при 10 Мбит/с около 56 минут, при 50 Мбит/с около 11 минут, при 100 Мбит/с около 5,6 минуты. Реальная скорость зависит от сервера, маршрута и диска. Разумный рабочий диапазон для такой загрузки — от нескольких минут до часа; после начала можно оценить фактический ETA по `curl`.

На стенде 2026-10-25 до загрузки было 30 ГиБ свободного места. Загрузка началась в 14:03 МСК
в игнорируемый Git каталог `data/raw/`. За первые 9 минут получено около 624 МБ: фактическая
скорость около 1,1 МБ/с, при ней весь файл займёт примерно 55–60 минут. Команда
`make fetch-russia` продолжает частичный файл и после завершения проверяет опубликованную
Geofabrik контрольную сумму MD5. До появления `.ok` файл не считать готовым.
