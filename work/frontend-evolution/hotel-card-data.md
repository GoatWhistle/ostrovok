# Источники карточек и метод проверки E12

2026-10-27. Перед реализацией и замером.

| Поле | Источник | Нет данных / ограничение |
|---|---|---|
| Фото | Хранимые записи hotel_supplier_content.details и OSM image; API HotelSummary.photos, thumbnail_url для совместимости | Первое пригодное фото, следующее при ошибке; без рамки, если ни одно не загрузилось. Источник в галерее. Отдельно от offers. |
| Категория | hotels.stars, исходный OSM/проверенный каталог | 1–5, не рейтинг гостей. Невалидное/неизвестное скрыто. |
| Адрес | OSM addr:street/addr:housenumber в существующем read model | Не подставлять город/координаты. |
| Цена | GET /hotels/{id}/offers с текущими check_in/check_out/adults/residency | Минимум только status available, не sandbox, доступность не 0, валидная валюта/сумма. Разные валюты отдельными минимумами, без конвертации. Неполный ответ явно назван частью предложений. |
| Найденные пожелания | matched.full/partial + fact active/confirmed_by_hotelier | none/unknown/computing/stale/conflicted/superseded не включать в преимущества. Ограничение partial и scope оставлять видимым. |

Пул offers: только карточки, пересекающие viewport, максимум 3 HTTP GET одновременно; один TanStack cache key hotel/dates/adults/residency. Отмена queued/active GET через AbortSignal при смене дат и уходе наблюдателя; 60 секунд staleTime. Перед/после замера сохранять число одновременно активных запросов, количество повторов при возвращении/смене оформления. Никакой отдельной LLM операции.

Положительный реальный пример: Cosmos Adler n11331531334, 2026-11-10 → 2026-11-12, 2 взрослых, residency ru. Один бесплатный GET к существующему :18083, без /chat/messages и без LLM: 14 тарифов, 7 категорий, status available, sandbox false, rates_complete true, checked_at 2026-10-27T02:18:16.857537Z, источник Островок. [Исходный ответ](evidence/e12-live-offers.json). Цена относится к этому ответу на эти даты, не обещанию будущей доступности.

Проверенная идентичность и запасной источник фото: https://adler.cosmosgroup.ru/galleries, официальный Cosmos Adler Hotel, ул. Просвещения 118Б/2, тот же отель. Галерея: https://adler.cosmosgroup.ru/files/hotel_gallery_items/1993_1732197287.webp и https://adler.cosmosgroup.ru/files/hotel_gallery_items/1214_1714986929.webp. Статические записи будут импортированы явно; никаких фото в production JSX или выдуманных ответов API.

Изолированный стенд сохраняет FakeLLM и отключённый провайдер тарифов: ошибка/отсутствие доступности проверяются реально. Положительный UI и крайние сочетания тарифов проверяются контролируемыми ответами в браузере/тестах, отдельно от доказательства реального GET. Реальные отели без фото/категории выбираются из импортированной БД; исходно 0 image tags, 82 категории, 0 supplier content.
