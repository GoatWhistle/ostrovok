## Как запустить без платной модели

Проверочный стенд — отдельный Compose-проект `hotel-evolution` с FakeLLM и PostGIS
([описание](evidence/stand.compose.yaml)); исходники бэкенда смонтированы из ветки.

```bash
docker compose -f work/frontend-evolution/evidence/stand.compose.yaml up -d
cd frontend
API_URL=http://127.0.0.1:18085 MAP_ASSET_URL=http://127.0.0.1:18082 npm run dev -- --port 5179
```

API: http://127.0.0.1:18085, интерфейс: http://127.0.0.1:5179. Подложки и шрифты карты отдаёт
фронтенд основного стенда :18082. Node 24.22.1 (`/tmp/hotel-node24/bin`), Chromium из Playwright.
Для замеров кадров нужен headed Chromium с `GALLIUM_DRIVER=d3d12` под WSLg ([E15](evidence/e15.md)).
Синтетические отели для проверок кабинета пересоздаются сидами `evidence/seed-h03-check.py` и
`evidence/seed-h07-check.py` только в изолированной базе.

## Ограничения и отступления

- Плавность панорамирования: цель p95 ≤33 мс не достигнута в плотном центре и на берегу
  на интегрированной графике через WSLg ([E15](evidence/e15.md)).
- Мобильный вид пользователь попросил не доводить: замеченная на 375 px вкладка «Чат» после выхода
  из большой карты без поля ввода не исследовалась ([E16](evidence/e16.md)).
- Промежуточный push: 2026-10-27 по прямой просьбе пользователя ветка опубликована до завершения
  E15–E17 (`85bcd18..55c6b9a`), поэтому правило AG02 о единственном итоговом push не соблюдено
  по решению пользователя. AG01 и AG03 — ниже.
- Физический телефон, скринридер и нативный браузер Windows не проверялись. Автономный FakeLLM
  разбирает только русские фразы реестра, поэтому английский текст ответа отельера ведёт к уточнению.
