# Интеграция двух сюжетов обложки

2026-10-27. E18 интегрирован и проверен: [отчёт](evidence/e18.md). Старый SceneReel заменяется в том же слоте Landing. На мобильном сохраняется существующий порядок и высота visual 46dvh; отдельного блока ниже нет.

Назначение движения — объяснение возможностей на первом экране. Одна управляемая временная шкала WAAPI и один RAF читают общее время для камеры, линии, печати, курсора, растворения и створок. Только opacity/transform для DOM; географическая камера и градиент линии обновляются через общий MapLibre. Easing берётся из действующих motion-токенов, конкретные времена — из согласованной постановки. Пауза замораживает всё, повтор только вручную.

Источники:

- http://localhost:8091/interlude.html?mode=sequence, сервер отвечает 200; исходники в основном дереве work/landing-variants. Просмотрены кадры маршрута 7,4 с и финала окна на 375 px, прочитаны choreography/route-story/window-story/typed-request/coast-panorama.
- Cosmos Adler Hotel n11331531334: [39.904065,43.4451502]. Существующий бесплатный GET /hotels/{id}/scene возвращает здание w291652014, высоту 12,8 м, контекст и камеры. Обложка использует общий map lifecycle/appearance renderer и эти данные. Поиск/LLM для демонстрации не запускаются.
- beach-walk.json — сохранённый пример длиной 242,86 м, округлённо 240 м / 4 мин при 4 км/ч; путь и расчёт относятся только к этому примеру. Конец [39.902377,43.446413], подписанная дорожка у пляжа.
- SVG-панорама и inset берутся из согласованного coast-panorama.js; inset строится из сохранённой OSM-геометрии. Это иллюстрация окружения, не проверенный вид из номера и не фактическое положение солнца. Vendor, панель прототипа, глобальные тестовые объекты не копируются.

Композиция: демонстрационное пожелание сверху, реальная карта и привязанные метки; объяснение результата снизу. В финале окно занимает верхнюю часть визуального слота, под ним требуемая подпись и компактная статичная мини-карта. Две доступные кнопки паузы/продолжения и повтора, без шкалы/скорости/режимов прототипа. Текст — RU/EN, текущие Manrope/токены/темы. Место под полный запрос зарезервировано, SR получает полную фразу без посимвольных объявлений.

Времена: первый полёт 0,4–4,5 с, линия 5,5–6,7, объяснение 6,7–7,4; удержание до 8,4. Второй полёт относительно 8,4: 0,4–2,9, dissolve 2,7–3,5, створки 3,3–5,1, финал 5,2–5,9. Второй сюжет заканчивается на 16,4. Печать 0,2–2,0 и 8,6–9,6; курсор исчезает по завершении.

Ввод/фокус/submit передают счётчик прерываний, чтобы новый ввод мог остановить и вручную возобновлённую сцену. Уход из viewport и скрытая вкладка ставят паузу без автоматического продолжения. Reduced motion и ошибка WebGL показывают статичный финал; медленная анимация не блокирует рабочий composer. Общая карта освобождается при уходе с обложки, скрытая основная карта остаётся при возврате на главную (максимум два GL).

Приёмка: pure timeline contract, реальный pause/resume/replay, скрытие и reduced motion, 8 сочетаний 375/1440×light/dark×RU/EN, отсутствие WebGL, медленная загрузка, реальная отправка FakeLLM без потери ввода; npm run verify и просмотр кадров приложения.
