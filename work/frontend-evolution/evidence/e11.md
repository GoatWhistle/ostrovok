## Ревью перед продолжением

Начатый Codex код E11 (незакоммиченный) прочитан целиком и сверен со спецификацией R2.24–R2.38,
бюджетом экземпляров архитектуры и приёмкой A17–A19. Основа признана корректной: ленивая
мини-карта через IntersectionObserver, общий контроллер оформления с профилем `mini`,
`interactive: false`, маршрут из той же выбранной геометрии, честные состояния без координат
и без WebGL, точка прямого отеля по GET без SearchResult. Найдено и исправлено:

- Заглушка `features/hotel-map/map-scale.tsx` с реэкспортом удалена, импорт ведёт в `shared/ui`.
- `hotelPosition` дублировал новую проверку координат; теперь использует `hotelPoint`.
- Кнопка «Открыть большую карту» показывалась без координат; теперь скрыта, есть только честное состояние.
- `HotelLocation` пропадал целиком при ошибке фонового обновления уже загруженного отеля;
  теперь скрывается только когда данных нет вовсе. Найдено тестом, а не чтением кода.
- Не было ни одного теста E11; добавлены модульные и браузерные проверки ниже.
- **Дефект A18, найден браузерной проверкой.** Возврат с большой карты ставил страницу в 966
  вместо 1200. Соседние колонки скрываются в том же коммите раньше отсоединения ref страницы,
  страница становится шире и короче, и чтение scrollTop при размонтировании давало обрезанное
  значение. Позиция теперь запоминается по событиям scroll; при возврате цель доприменяется,
  пока дорастает контент (до первого ввода пользователя или 2 с), и не перезаписывается
  незавершённым восстановлением, в том числе при двойном ref-вызове StrictMode.

## Что сделано

Раздел «Расположение» в конце полной страницы: адрес либо «Адрес не указан в источнике»,
мини-карта и «Открыть большую карту». Мини-карта создаётся при первом появлении раздела
в видимой области, без рельефа, объёмов, крыш, окон и свечения, без вращения/наклона/жестов.
Оформление (ночная карта/игрушечный город) общее с основной картой. Масштаб и атрибуция
вынесены в `shared/ui`. Большая карта из страницы сохраняет отель и маршрут; кнопка выхода
называется «Вернуться к отелю» и возвращает страницу на прежнюю позицию.

  Новые тесты: координаты (валидные, NaN, вне диапазона), профиль мини-карты обоих пакетов,
  состояния раздела (адрес, нет адреса, нет координат, ошибка фонового обновления, ленивое создание),
  обзор камеры прямого отеля, навигация страница → большая карта → страница → панель,
  отложенное восстановление прокрутки, прерванное восстановление, обрезание при размонтировании.
- [Браузерная проверка](e11-location.json), `check-e11-location.cjs`, реальный WebGL, reduced motion:
  - A17: Cosmos Adler, после «Показать на карте» у пожелания «рядом с морем» мини-карта показывает
    `g_route_n11331531334` (LineString из API) и маркер точно на координатах отеля (смещение 0 px).
    До появления раздела мини-карты нет; на странице 2 canvas, основной тот же и неактивен.
    Pitch/bearing 0, scrollZoom/dragPan выключены, рельефа и видимых объёмов нет;
    колесо над мини-картой прокручивает страницу (1200 → 960).
