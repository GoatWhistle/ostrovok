# E09: большая карта и компактный отель

2026-10-27. Исходный коммит `675e6d1`; изолированный FakeLLM API :18085, Vite :5179.

Кнопка карты раскрывает тот же основной MapLibre instance на viewport. Обычные header,
список и чат скрыты; чат остаётся смонтированным. Список освобождает DOM, сохранив scroll.
На desktop карточка справа, на телефоне снизу. Кнопки сворачивания и закрытия доступны
без жеста. `HotelSummaryCard` общий со списком: реальные фото/категория/адрес и только
пригодные совпадения, цена через общий offers-cache. Неподтверждённые поля не добавляются.
Без выбранного отеля карточки нет; прямой hotel ID получает сведения через GET.

Отступ камеры рассчитывается по реальному прямоугольнику карточки. Он меняет экранное
положение географического центра без изменения координат, zoom, pitch и bearing.
Кнопки и подписи учитывают карточку как препятствие. Смена оформления остаётся доступной.
Используется [MapLibre PaddingOptions](https://maplibre.org/maplibre-gl-js/docs/API/type-aliases/PaddingOptions/).

Escape сначала обрабатывает открытый popover; следующий выходит из большой карты.
Modal dialog сохраняет приоритет Escape. Отдельное закрытие карточки снимает выбор,
оставляя большую карту. Очистка локальных сведений до изменения URL убрана: она успевала
применить старую сценическую камеру. Выход из выбора не инициирует обзор; новые границы
нового поиска по-прежнему применяются. Кнопка обзора остаётся явным действием.

«Открыть страницу отеля» и «Номера и цены» ведут к полноценной странице на всю прежнюю
область карты, сохраняя origin. Переход к номерам ждёт появления секции в DOM и переводит
фокус только после этого. Наблюдатель отключается при нахождении секции либо уходе.

## Проверки

- `npm run verify`: 36 правил, TypeScript/Biome, 459 тестов в 84 файлах, production build.
- `e09-flow.json`: WebGL/SwiftShader, 1440×900, карта 1440×900; список 1800→1800,
  один canvas и тот же textarea; черновик сохранён. Камера [39.904065,43.4451502],
  zoom16.6/pitch30/bearing22 сохраняется при раскрытии, Escape, странице и закрытии карточки.
  Выбранная точка x512, карточка начинается x1024; кнопки x964. Правый отступ416px.
  Номера получают фокус `n11331531334-rooms`. Ошибок JS и POST chat/messages нет.
- `e09-matrix.json`: 375×812/1440×900 × light/dark × RU/EN, 8 сценариев **без WebGL**,
  проверяют компоновку и честный fallback. Карточка мобильного режима 343×365.39,
  свёрнутая343×60. Нет горизонтального overflow. Карта и полная страница занимают viewport,
  стиль toy-town сохраняется после возврата. Закрытие карточки не закрывает карту.
- Геометрия камеры, восстановление списка без выбранного отеля, Escape/popover/modal,
  асинхронный якорь номеров закреплены регрессионными тестами.
- `e09-motion.json`: ещё 8 сочетаний с обычными анимациями, без WebGL. Вход/возврат,
  раскрытие/сворачивание mobile-карточки и её закрытие проходят без JS-ошибок и POST.
- `e09-focus.json`: последовательность событий подтверждает, что фокус остаётся на кнопке
  раскрытия, а повторная привязка scroll-ref в StrictMode его не забирает.
- После серии переходов выявлено движение камеры от hover-превью при закрытии popover,
  а не от пакета оформления (`e09-cycles-trace.json`). Введено отдельное previewing-состояние:
  геометрия подсвечивается без камеры, явное открытие факта по-прежнему кадрирует её.
  Прямая смена оформления даёт ноль jumpTo/easeTo/flyTo/fitBounds (`e09-style.json`).
- `e09-cycles.json`: реальный WebGL, выбор маркера Cosmos, 10 desktop и 2 mobile цикла.
  Одинаковый canvas, каждый возврат фокусирует кнопку раскрытия. Центр/zoom16.3/pitch25/
  bearing15 сохранены во всех циклах и после toy-town. Desktop-точка (512,450), карточка
  начинается x1024; mobile-точка (187.5,215.3), карточка начинается y430.6. Ноль JS-ошибок,
  POST сообщений и горизонтального overflow. Итоговые снимки обоих экранов просмотрены.

Первый браузерный запуск не подключился к остановленному dev-server; сервер поднят заново.
При первом замере закрытия mobile-карточки счётчик DOM читался до React commit; повтор
ожидает фактическое удаление. Первый снимок WebGL после возврата успел захватить начало
анимации; итоговые снимки ждут её завершения. Это не положительные доказательства до повтора.
Сохранились прежние предупреждения о размере MapLibre/PMTiles chunk и PostCSS.
