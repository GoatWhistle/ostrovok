# E08 — жизненный цикл основной карты

2026-10-27. Основная карта остаётся в HomePage при смене чата, вкладок и возврате на главную. Её инициализация защёлкивается после первой камеры; последующее отсутствие данных не пересоздаёт instance. Общий hook перенесён в shared/geo/engine для использования обложкой и другими картами.

Один собственный ResizeObserver управляет размерами (`trackResize: false`); IntersectionObserver и visibilitychange определяют активность. Явная видимость рабочего экрана останавливает работу до уведомления наблюдателей. Скрытие останавливает перелёты, route RAF, оконный worker, обновления сцены и тяжёлые обработчики. Контроллер оформления хранит последний snapshot до возврата. Камера применяет только новые команды: раскрытие не повторяет старый search viewport. Прерванная отрисовка существующего маршрута возвращается готовой линией.

Исправлена лишняя запись history при нажатии логотипа: очистка transient-состояния больше не создаёт второй переход. Back возвращает к прежним отелям и ручному ракурсу.

Проверки:

- `npm run verify`: 36 правил, typecheck/lint, 428 тестов в 73 файлах, build. Тесты камеры проверяют десять скрытий и отложенное применение новой команды; тест наблюдателей — размеры, viewport, скрытую вкладку и cleanup.
- [Реальный WebGL](e08-browser.json): десять Chat → Map при 375 px сохраняют одну основную canvas и её камеру. Во время 30 секунд скрытия после 3 секунд стабилизации: 0 render, 0 RAF, 0 worker postMessage, 0 активных оконных workers, 0 новых `/map/scene`.
- Искусственная потеря WebGL через WEBGL_lose_context показывает состояние недоступной карты; восстановление сохраняет canvas и возвращает карту. Проверен уход контейнера из viewport и возврат.
- Логотип → главная → Back: основной canvas сохраняется, на главной максимум два canvas (скрытая основная карта и прежняя обложка), обратно один; ручная камера сохранена. Кадр e08-restored-mobile.png просмотрен.

Первый расширенный прогон выявил лишний history-переход; исправление проверено повторно. Один промежуточный прогон совпал с HMR-переносом hook и получил старый canvas; финальный прогон выполнен без изменения исходников. Полноэкранная карта и страница отеля используют этот жизненный цикл после E09/E11; их конечная матрица проверяется в E16.

Основание для resize/stop и событий восстановления: [MapLibre Map API](https://maplibre.org/maplibre-gl-js/docs/API/classes/Map/). Проверка использует Chromium SwiftShader; аппаратная производительность на телефоне не измерялась.
