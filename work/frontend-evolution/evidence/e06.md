# E06 — игрушечный город

2026-10-27, изолированный Compose hotel-evolution, FakeLLM. [Направление оформления](../toy-town-design.md).

Пакет toy-town использует общие географию, камеру, солнце, маркеры и запросы. Собственная палитра земли, воды, дорог, классов зданий и подписей; матовые стены и крыши. Крыша повторяет контур и фильтр исходного слоя: декоративная толщина 0,25 м не попадает в данные или факты. Выбранное здание получает матовый материал без загрузки текстуры. Оконный worker, огни и glow отключены. Лёгкий профиль mini не включает terrain/объёмы/свет.

Проверки:

- `npm run verify`: 36 правил, typecheck/lint, 424 теста в 70 файлах, production build. Остались прежние предупреждения PostCSS и крупного home chunk.
- Реальный WebGL: город z14.99/16.2, выбранный Abris z17.2, берег, горный участок вне покрытия зданий, уровни качества 0–3. Плоские контуры остаются на каждом уровне; glow выключен.
- 1440 px, светлая тема/RU, дневное солнце; 375 px, тёмная тема/EN, 20:00. Подписи, маркер выбранного отеля, масштаб и время работают; нулевые ошибки HTTP/JS в повторной мобильной и горной проверках. Скриншоты e06-*.png лежат рядом локально. Полная общая матрица действий будет пройдена в E16.
- Тесты крыш проверяют сохранение фильтра известной высоты, исключение выбранного здания, идемпотентность и удаление только слоёв пакета.

В стенде исправлен bbox собственного синтетического региона отельера: он ограничен двумя демо-отелями и больше не перехватывает сцену всего Сочи. Исправлен dev proxy `/maps`: `MAP_ASSET_URL` указывает на существующий Nginx с локальными ресурсами; без этого Vite отдавал HTML вместо PMTiles и 404 вместо спрайта. Исходный рабочий стенд не менялся.

Метод: Playwright/Chromium SwiftShader, реальные GET API без подмены, тестовый доступ к экземпляру через React fiber. Проверялись изображения и свойства слоёв; это не аппаратный FPS-бенчмарк.
