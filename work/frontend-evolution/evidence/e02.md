# E02 — полноэкранный чат и раскрытие выдачи

Проверено 2026-10-27 на изолированном стенде E00. Первый submit открывает чат на всю рабочую область. Уточнение, ожидание, ошибка и первая пустая выдача сохраняют этот режим; первая непустая выдача раскрывает список/карту/чат. После раскрытия пустой ответ оставляет рабочую область. Флаг раскрытия хранится в sessionStorage отдельно для диалогов.

Черновик хранится отдельно от сообщения в полёте, переносится при получении ID нового диалога. Провайдер дат больше не пересоздаёт дерево при обновлении запроса. Тот же textarea сохраняет DOM, текст и фокус. Прокрутка следует за новыми сообщениями только у нижнего края, при ручном чтении сохраняется. Первый ввод/фокус останавливает текущую обложку; её замена и окончательные контролы остаются E18.

Проверки:
- `npm run verify`: 36 правил, типы, lint, 67 файлов / 416 unit-тестов, сборка успешно. Исходные предупреждения PostCSS и размера home-chunk сохраняются.
- `E2E_BASE_URL=http://127.0.0.1:5179 npm run e2e -- e2e/chat-reveal.spec.ts --workers=2`: 9 сценариев. Восемь сочетаний 375/1440 × light/dark × RU/EN; на 375 reduced motion. Отдельно ошибка, повтор исходного запроса, первая пустая выдача и reload через GET без нового POST.
- Проверены идентичность DOM поля, фокус, следующий черновик при задержанном ответе, пустая выдача после непустой. Кадры `e02-reveal-*.png`, журнал `e02-browser.log`. В этих тестах WebGL отключён: также проверяется доступность списка при отказе карты, но это не проверка графики карты.
- Изначально Playwright `check()` проверял radio синхронно до завершения перехода React Router. Снимок подтверждал выбранную вкладку. Теперь тест нажимает реальный control и ожидает видимое содержимое; все 9 сценариев прошли.

Ограничения: мобильная системная клавиатура не воспроизводится настольным Chromium. Её проверка на устройстве остаётся в итоговом E16. Производительность настоящего WebGL и остановка фоновой основной карты относятся к E08/E16.
