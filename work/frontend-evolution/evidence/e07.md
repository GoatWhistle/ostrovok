# E07 — переключатель оформления

2026-10-27. Иконка карты открывает два варианта с нативными radio: «Ночной город» и «Игрушечный город». Активный вариант отмечен. Выбор сохраняется в localStorage и `style` URL; неизвестное значение нормализуется. При ошибке контроллера сохраняются прежние оформление и URL, доступен ручной повтор. Отказ storage не мешает применению.

`npm run verify`: 36 правил, typecheck/lint, 426 тестов в 71 файле, build. DOM-тесты проверяют ошибку, сохранение прежнего radio, успешный повтор и недоступный storage.

Реальный Playwright/WebGL на изолированном API, без подмены поиска: десять смен кнопкой сохраняют все source objects и камеру (ручные zoom 14.5, pitch 45, bearing 23), выбранный отель n4712092442. Ноль POST и JS-ошибок. Проверены искусственный отказ зарегистрированного renderer и повтор, смена UI-темы/языка, reload, новый URL без style с сохранённым выбором, неизвестный style. Мобильная кнопка 44×44, горизонтального переполнения нет. 1440/375 px, RU/EN, светлая/тёмная тема. Кадры e07-picker-*.png просмотрены локально.

Это время применения JS-контроллера, не время полного кадра и не аппаратный FPS-тест. В Vite тест импортирует фактически загруженный URL модуля с HMR query, чтобы обращаться к тому же singleton, что UI.

Первый диагностический прогон ждал глобальное событие load и имел слишком короткий timeout снимка WebGL. Повтор ждёт готовности самого меню; снимок имеет отдельный timeout. Ограничение проверки времени полного кадра остаётся для E16.
