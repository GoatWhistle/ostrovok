# H05: рабочая область отельера отдельно от предпросмотра

2026-10-27. Код рабочего пространства: `fc7e3cf`, исправление дат после браузерной проверки в коммите с этим отчётом.

AH16–AH19 проверены на FakeLLM/PostGIS через реальные GET: одна шапка, короткие темы очереди,
вопрос первым на телефоне, предпросмотр отдельно. После закрытия предпросмотра черновик сохранён,
фокус возвращается на кнопку. Выбор вопроса переводит фокус на его заголовок.

Матрица: 375/1440/2560 × шрифт 100/125%, RU/dark, Chromium; [числа и геометрия](h05-browser/results.json).
Наложение дат при 375/125% воспроизведено и исправлено общим auto-fit полей с минимумом 11rem.
Диалог центрирован и ограничивает overscroll. Длина текста ограничена prose-токеном; страница сохраняет полную ширину.

Настоящий browser zoom 200% задан через отдельное тестовое расширение Chromium и chrome.tabs.setZoom;
getZoom=2, innerWidth=720, devicePixelRatio=2: [результат](h05-browser/zoom.json).
Метод: [Chrome Tabs](https://developer.chrome.com/docs/extensions/reference/api/tabs#method-setZoom),
[Playwright extensions](https://playwright.dev/docs/chrome-extensions). Профиль браузера одноразовый.
Снимки проверены визуально; даты больше не пересекаются, горизонтального overflow нет.

`npm run verify`: 36 правил, typecheck/lint, 528 тестов и сборка прошли. [Лог](h05-verify.log).
RU/EN и обе темы для кабинета проверяются полной матрицей H07; текущие живые проверки не вызывают платную модель.
