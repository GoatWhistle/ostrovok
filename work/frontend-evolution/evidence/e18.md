`npm run verify`: 36 правил, typecheck, lint, 434 теста в 74 файлах, production build. Home chunk теперь около 47,6 kB вместо прежнего объединённого с картой; большой MapLibre/PMTiles chunk остаётся ленивым (предупреждение размера сохранено). Это размеры сборки, не замер скорости реального устройства. Старое предупреждение PostCSS сохраняется.

Во время проверки обнаружены и исправлены: мобильная метка отеля за пояснением (кадрирование учитывает доступную высоту); раскрытие источников за верхней границей; недостающий родительский region russia в изолированной БД (добавлена запись с bbox -180,41,180,82 по существующей схеме seed/geography; это не импорт геометрии России). Первый fallback прогон с FK-ошибкой не считается успешным, повтор сохранён отдельно как текущий результат.

Браузерные скрипты используют стандартную WAAPI currentTime/playbackRate только для воспроизводимых снимков. Управление прототипом и тестовые globals в продукт не внесены. В матрице `finalVisible` пуст из-за устаревшего селектора имени CSS module; наличие финала подтверждено снимками, этот массив не служит доказательством. В sequence `cards` также не использован для измерений; высота измерена отдельным mobile прогоном.

[WAAPI currentTime](https://developer.mozilla.org/en-US/docs/Web/API/Animation/currentTime) и [pause](https://developer.mozilla.org/en-US/docs/Web/API/Animation/pause) использованы для единой паузируемой шкалы. Сохранённая геометрия маршрута и OSM-inset относятся только к демонстрации Cosmos Adler, не подменяют API поиска. [Решение интеграции](../cover-integration.md).
