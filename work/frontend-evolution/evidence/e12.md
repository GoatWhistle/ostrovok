# E12: карточки и подробности отеля

2026-10-27, `feat/hotel-agent-mvp`, до коммита HEAD `9cde5d9`.

Карточка списка показывает настоящее доступное фото, категорию 1–5, адрес,
только full/partial с актуальным фактом и минимальную цену по каждой валюте для
выбранных дат/гостей. Условие partial и scope остаются видимыми. После ошибки
фото выбирается следующее; после последнего рамка исчезает. Нет ложной цены
для sandbox, отсутствующих дат, недоступного/чужого ответа или нулевой доступности.

Подробности: компактное имя, первые три найденных пожелания, остальные и сводка
неподтверждённых в раскрытии; затем номера/тарифы, виды, фотографии, удобства и
доказательства. Устаревшее/конфликтное не подписывается «Подходит». Высота/этажность
убраны из шапки. «Номера и цены» переводит фокус в раздел; возврат из комнаты —
на её кнопку. Фото доступны при ошибке тарифов. Удобства объединены по известным
кодам/точному тексту, четыре сразу, остальные раскрываются; включение в тариф
не обещается. Общий pets_policy различает false/unknown/0 и неизвестный период оплаты.

## Данные и границы доказательства

[Источники и метод](../hotel-card-data.md), [реальный ответ тарифов](e12-live-offers.json),
[реальный GET отеля](e12-real-hotel.json), [новый реальный диалог FakeLLM](e12-conversation.json).
Один бесплатный GET на исходном :18083 дал Cosmos Adler, 10–12 ноября, 2 взрослых:
14 тарифов/7 категорий, минимум 12000 RUB за всё проживание. Это снимок ответа,
не обещание будущей доступности. Платная модель не вызывалась.

Фото импортированы в настоящую изолированную PostGIS через
`cd backend && DATABASE_URL=... uv run python ../work/frontend-evolution/import-hotel-media.py`.
JSON содержит URL и источник каждого фото. Основное — из реального ответа Островка,
два запасных — официальная галерея. Официальный сайт дал SSL timeout при проверке;
поэтому его фото не стоят первыми. У Cosmos в OSM нет адреса/категории — эти поля
не выдуманы. Реальная категория: Антика `n10967527654` (3); City Park Hotel
`n736761646` (4) виден в записи списка. Abris без категории/адреса/фото, AIDA с адресом.
Полный и неизвестный результат есть в сохранённом диалоге. Реальный partial пока
не найден в вычисленном срезе; условия/stale/conflict проверены отдельными тестовыми
ответами и не названы реальными сведениями об этих отелях.

Изолированный поставщик тарифов остаётся отключённым. Положительный UI использует
перехваченный в тесте реальный снимок Островка; другие ответы no_offers и крайние
сочетания явно контролируемые. Матрица E12 запускается без WebGL, чтобы отдельно
проверить доступность списка/карточки при отказе карты; карта проверяется E04–E11/E15.

## Проверки

- Backend: Ruff, mypy; 908 unit/contract/integration прошли на реальной PostGIS,
  включая запись photos → search/get_hotel → HTTP schema без вызова offers.
  Первый прогон ошибочно не задавал DATABASE_URL для части старых интеграционных
  тестов; остановлен и повторён с DATABASE_URL/TEST_DATABASE_URL=:15435, FakeLLM.
- Frontend: полный `npm run verify`: 36 правил, TypeScript, Biome, 444 теста,
  сборка. Новые проверки: пул 3/отмена очереди и активного запроса; минимумы валют,
  даты/гости/ID, sandbox/0; фильтр фактов, ошибочные фото, категория и pets_policy;
  первые три пожелания, раскрытие, отсутствие положительной подписи stale.
- [8 сочетаний](e12-matrix.json): 375/1440 × light/dark × RU/EN, reduced motion,
  один offers GET на карточку, нет JS ошибок и горизонтального переполнения.
- [Сценарий](e12-interactions.json): rooms focus, комната/Back с возвратом фокуса,
  галерея 2/3, настоящий загруженный снимок в галерее/списке, цена 12000 с основанием;
  максимум 3 GET одновременно; Cosmos 1 GET при переходе подробности → список.
  Отменённые при прокрутке запросы не считаются успешными ответами.
- [Крайние данные](e12-edges.json): длинное имя/адрес, partial с номером и этажом,
  неизвестный/stale, короткое имя, отсутствующие поля, 404 первого фото. 375/1440 и
  дополнительно 320 при 200% тексте. Найденное переполнение устранено ограничением
  grid tracks и переносами: scrollWidth карточки совпадает с clientWidth.
