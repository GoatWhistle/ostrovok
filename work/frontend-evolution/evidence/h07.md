# H07: повторная проверка кабинета

2026-10-27, SHA `3b4f6c6`. [Реальный браузерный сценарий](h07-live.json),
[тестовый отель](h07-seed.json), [три новые e2e-регрессии](h07-e2e.txt).

В изолированной PostGIS/FakeLLM создан отдельный явно синтетический h_demo_completion_check.
Ответ false, confirm, correct, skip и reopen прошли HTTP 200. Reload читает ответ, связанные ID,
исправленное значение и статус. RU→EN→RU, смена темы, выход на главную и Back сохраняют ввод.
Платные модели и авторизация не проверялись. Контролируемые 503/follow_up/conflict в e2e
доказывают поведение UI; реальные мутации отдельно подтверждены API и PostGIS.

45 интеграционных тестов прошли, включая гонки answer/skip и correct/confirm: [лог](h07-integration.txt).
Первый запуск 893 passed / 28 errors был остановлен отсутствием DBMATE_BIN в окружении;
после явного DBMATE_BIN=/tmp/evolution-dbmate все 45 integration прошли.

Матрица кабинета: [H06, 8 сочетаний](h06-browser.json), [H05, 125% и 200%](h05.md).
Предыдущие H01/H03/H04 регрессии входят в текущие 529 unit; новые browser e2e 3/3.
