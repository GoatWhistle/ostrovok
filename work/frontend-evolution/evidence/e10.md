# E10: расширенная панель и отдельная страница

2026-10-27, `feat/hotel-agent-mvp`, исходный HEAD `8175edd`.

Список и панель теперь имеют разные размеры. При выборе отеля левая панель занимает
треть рабочей ширины; ручное изменение ширины доступно списку и не перезаписывается
открытием отеля. «Все отели» возвращает список, прежний размер, scroll и фокус.
Отдельная кнопка открывает `/hotels/:id`: из панели подробности занимают центральную
область вместо карты, слева список, справа тот же чат. Прямой вход и `from=map`
занимают весь viewport; есть видимый возврат, скрытая шапка не доступна клавиатуре.

Одна композиция HotelContent используется для панели и страницы. Основной MapLibre
остаётся в прежнем DOM-контейнере, скрывается и останавливается на странице.
Прокрутка панели/страницы/факта сохраняется отдельно по диалогу и отелю. Даты, гости,
сравнение и выбранная категория номера общие; категория дополнительно привязана к
отелю и конкретному проживанию. Прямой вход загружает настоящие GET; без запроса
сначала выводятся имеющиеся актуальные факты с ненулевым значением (false и 0 допустимы),
остальные доступны в полном разборе. Ошибка GET имеет retry и возврат.

Переходы используют существующий View Transition и токены длительности. Внешний
последовательный Swap заменён единственным содержимым панели: во время перехода
нет двух живых обзоров с одинаковыми HTML ID. Внутренние переходы фактов сохранены.
Reduced motion использует общий предусмотренный режим.

Стек возврата проверяет внутренние адреса, хранит вложенный origin и сохраняет
текущее оформление/выбор при возврате из большой карты. Прямая ссылка без origin
возвращает на главную. Визуальный полноэкранный режим карты реализуется следующим E09;
здесь проверен маршрут возврата, а не объявлена готовность E09.

  Матрица без WebGL отдельно проверяет доступность остального интерфейса при отказе карты.
