# H06: отмена, фокус и закрытие

2026-10-27, исходный SHA `42a3b03`. [Браузерная матрица](h06-browser.json): 8/8 сочетаний
375/1440 × RU/EN × light/dark, реальные GET из FakeLLM/PostGIS, ни одного POST/PATCH.

AH20–AH23: свернуть сохраняет текст, отмена возвращает сохранённое значение и сбрасывает ошибки;
Escape внутри редактора закрывает его, следующее нажатие возвращает из факта. Возвращается
именно исходная строка и scroll, либо действие у сохранённого ответа. Очередь на телефоне имеет
«К вопросу», Escape и восстановление фокуса/scroll. Повторный выбор вопроса не снимает выбор.
Настройки возвращают фокус на триггер и сбрасываются по pathname; тема/язык не меняют этот ключ.
Вложенный select поглощает свой Escape. Предпросмотр сначала фокусирует заголовок, при закрытии
возвращает фокус. Полная таблица из 22 контролов и серверные мутации сведены в H07.

Проверка motion: раскрытия через usePresence, opacity ≤200ms, выход 140ms, клавиатурные действия
instant; закрывающиеся поверхности inert. Reduced motion проверен во всей матрице; быстрые
Enter/Space обратимы. Декоративных анимаций строк не добавлено. Фокус после сохранения редактора
не остаётся на BODY. Нативный диалог закрывается штатно.

`npm run verify`: 36 правил, 529 тестов, typecheck, lint и build: [лог](h06-verify.txt).
Добавлена регрессия: сохранённый при сворачивании ввод исчезает только при явной отмене.
