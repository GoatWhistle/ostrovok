# Toy-town — визуальное решение E06

Замысел: тот же географически точный город выглядит как настольный архитектурный макет. Поля интерфейса, Manrope и текущая компоновка остаются прежними; меняется карта.

Базовые цвета: земля #e6ddbd, вода #79bccb, зелень #86aa7e, крыши #b46b55, дороги #f5efd9, подписи #304b53. Стены светлее крыш; объекты различаются по реальному классу. Неизвестный класс получает нейтральный цвет. Высота не придумывается: при отсутствии данных остаётся плоский контур.

Композиция сохраняет текущую камеру пользователя. Наклон даёт вид миниатюры существующими средствами карты; смена оформления сама камеру не двигает. Слои: рельеф → реальное землепользование/вода → дороги и контуры → матовые стены/крыши → факты/маршрут → подписи и маркеры. Основной акцент — объём города. Размытие и дополнительный декоративный интерфейс не нужны.

Проверка решения против задания: одной перекраски недостаточно. Добавляются отдельные матовые верхние поверхности зданий по их исходным контурам; выбранный отель получает матовые стены и крышу в существующем custom renderer. Неоновые ореолы и декоративные окна отключены; свет учитывает прежнее направление солнца. Кровельная пластина — условная деталь оформления, не измеренная высота и не новый факт. Карта, мини-карта, легенда, подсветка и маршруты используют один пакет.

Проверки: реальный город/берег, плотная застройка, отсутствие высоты, день/ночь, z10–17, качество 0–3, 375/1440, RU/EN. Пакет neon сравнивается на тех же данных, камера при переключении сохраняется.
