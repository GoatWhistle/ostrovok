# История подборов

Правый чат сохраняет каждую начатую беседу в истории текущего браузера. Название берётся из
первого сообщения пользователя. Кнопка «История чатов» раскрывает список; выбранный чат
помечен. «Новый поиск» сбрасывает активный ID, выбранный отель и сравнение, сохраняя список
старых бесед. Следующее сообщение создаёт новый ID на сервере без прежнего контекста.

При выборе старого чата фронтенд запрашивает его из PostgreSQL по сохранённому ID. Отсутствующий
на сервере ID удаляется из локальной истории. Пока сообщение отправляется, переключение чатов
заблокировано, чтобы ответ не попал в другой диалог. Клавиатурный порядок: история, новый поиск,
элементы списка, сообщения, поле ввода. На мобильном панель истории ограничена по высоте и
прокручивается отдельно от переписки.
