# Work

Internal artifacts the team and the skills produce along the way: they are not organizer material
(`brief/`), not session state (`context/`) and not product docs (`docs/`). Read on demand by the skill
that owns each one. Scrubbed at submission.

| Path | Written by | What |
|---|---|---|
| `plan.md` | план работ | Задачи до готового MVP, критерии готовности, риски |
| `naming.md` | `naming` | Name candidates, scores, finalists, taglines, name origin |
| `brand/` | `brand-identity` | Logo gallery and the chosen mark's rationale |
| `design/` | `refero-style` | Style extraction, source-site screenshots, conflicts resolved |
| `competitors.md` | `competitors` | Rivals, threat tiers, criterion scores |
| `repo.json` | `repo-meta` | GitHub description and topics proposal |
| `frontend/` | frontend implementation | Integration plan, review verdict and validation |
| `screens/` | frontend workflows | Screen specifications |
| `audits/` | audit workflows | Dated findings and check results |
| `evals/` | live search evaluation | Fixed query set and full results |
| `building-texture/` | building texture experiment | Satellite references, generation prompt, GLB builder and local preview |
| `session-state-2026-10-25.md` | context compaction | Previous measured stand state and next actions |
| `research/` | `research` | Investigation notes |
| `template-development.md` | template maintenance | History of work on this template; discard when starting a hackathon |
| `submission/` | `submission` | Platform confirmations and screenshots with timestamps |

A file here keeps its full working detail; its one-line conclusion goes to
[`context/README.md`](../context/README.md) «Current facts».
