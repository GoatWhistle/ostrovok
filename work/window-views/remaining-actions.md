## 1. Исправить потерю найденного ориентира за границами города

**Следующее конкретное исправление, ещё не реализовано.**

Реальный запрос: «В Петрозаводске хочу номер с видом на Онежское озеро».
`resolve_spatial_requests` правильно расширяет поиск на радиус пожелания и находит
`r1308279`, «Онежское озеро», координаты представительной точки `[35.0277084, 62.1861201]`.
Городской bbox: `[34.186269775902396, 61.70045449395683, 34.540682319097606, 61.861622116043165]`.

Затем `LandmarkResolver` повторяет поиск кандидатов только внутри городского bbox и
не включает переданный `fallback` в набор для смысловой проверки. В набор попадают
«Долгое озеро», «озеро Угольная Ламба», «Четырёхвёрстное озеро», родник «Онежский».
После их обоснованного отклонения правильный ранее найденный объект теряется.
Это воспроизведено прямыми вызовами репозитория и `resolve_spatial_requests` на стенде.

Действия:

- Добавить регрессию в `backend/tests/unit/application/test_landmark_resolution.py`:
  правильный объект вне города найден предыдущим шагом, внутри города есть похожие
  неподходящие объекты; правильный объект обязан участвовать в смысловой проверке.
- Включить ранее найденный объект в кандидаты без дублирования ID. Сохранить право
  смысловой проверки его отклонить: не принимать любой fallback автоматически.
- Проверить аналогичные случаи больших озёр, рек, гор за границей города.
- Повторить полный запрос на стенде и проверить геометрию именно Онежского озера,
  карточки, лучи и профиль препятствий. Не заменять вид близостью к берегу.

Файлы: `application/spatial_resolution.py`, `application/landmark_resolution.py`,
`application/agent/requested_tools.py` внутри `backend/src/hotel_agent/`.

## 2. Разрешать отсутствующие в каталоге ориентиры

Для «Москва-Сити» точная проверка локальных POI, зданий и территорий не нашла сам комплекс.
Есть одноимённые станции, банки, отель и другие объекты. Репозиторий предлагает 16
неподходящих достопримечательностей со словом «Москва»; отклонение модели корректно.

Нужен общий механизм внешнего поиска идентичности ориентира с проверяемым OSM ID,
геометрией, типом объекта и источником. Координата одноимённой станции или текстовое
упоминание не доказывают вид. Для комплекса отдельно определить, на какие его реальные
здания проверяется панорама; не принимать высоту отсутствующей геометрии за ноль.

Пробы Overpass: private.coffee — тайм-аут, overpass-api.de — HTTP 406. Доступность
онлайн-дозагрузки не подтверждена. Локальный полный импорт России имеет документированные
пропуски: см. `work/geography/verification.md`. Не снимать ограничения полноты ради выдачи.
