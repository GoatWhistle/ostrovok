# Mapbox: выбранная визуальная система

Источник — присланные пользователем 25.10.2026 Markdown-описание, JSON и CSS-токены.
Визуальный мир выбран: тёмные панели, географические данные, синие интерактивные акценты.
Оригиналы сохранены без изменения: [референс](source/mapbox-reference.txt),
[токены](source/mapbox-tokens.json), [SHA-256](source/manifest.json).

Сайт источника: https://mapbox.com. URL конкретной страницы Refero не передан.
Скриншоты исходного сайта не переданы; приложение строится по токенам и текстовому референсу.
Текущий scope — продуктовый интерфейс поиска, а не маркетинговая копия сайта Mapbox.

## Правила переноса

- CSS из сообщения пользователя имеет приоритет над вариантами типографики в JSON.
- Палитра переносится в palette; компоненты используют semantic tokens.
- Тёмная тема — основная визуальная опора; светлая сохраняет роли и проходит те же проверки.
- Полная рабочая ширина и панели; исходная маркетинговая ширина не ограничивает приложение.
- Sentence case и читаемые подписи вместо рекламных all-caps.
- Синий обозначает действие/выбор, зелёный — подтверждение; статус содержит текст и иконку.
- Контраст 4.5:1, видимый фокус, цели касания 44 px.
- Cera Pro отсутствует; применяется предоставленный system fallback. Внешние шрифты не загружаются.
- Карта показывает только геометрию и высоты, полученные через API. Платный Mapbox SDK не нужен.
- Тени не изображают отсутствующие данные и не скрывают элементы карты; анимация сообщает смену выбора.

Полные цвета, масштабы, компоненты, рекомендации Do/Don't, примеры и сходные бренды находятся
в неизменённом исходном тексте; они не сокращались при архивировании.
