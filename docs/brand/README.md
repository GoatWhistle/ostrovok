# Знак и логотип

Исходники знака в SVG. Из них собираются favicon и иконки приложения, и картинки README в `docs/readme/`.

Знак: сложенная карта из трёх полос на сетке 64. Крайние полосы `mark-base` (кобальт, `--mark-side`), средняя `mark-accent` (лайм, `--mark-fact`). Логотип: знак и слово «factmap», Manrope 800, трекинг −5%, только строчные.

| Файл | Где используется | Требования |
|---|---|---|
| `wordmark-light.svg` | Логотип (знак и слово) на светлом фоне | Текст переведён в кривые, `viewBox` без лишних полей, читается при ширине 280–420 px |
| `wordmark-dark.svg` | Логотип (знак и слово) на тёмном фоне | Та же геометрия, цвета для тёмного фона |
| `symbol.svg` | Favicon, иконки приложения, знак в презентации и в картинках README | Читается при 16 px, один цвет допустим |
| `card-scene-light.jpg`, `card-scene-dark.jpg` | Правая половина карточки для соцсетей (`og-ru.png` светлая, `og-en.png` тёмная) | Кадр ролика с главной страницы: город у «Космоса» в Адлере днём и ночью, без подписей на русском в тёмном кадре |

Цвета знака совпадают с токенами интерфейса из `frontend/src/shared/styles/tokens/`. Исходники и
варианты, которые не используются, здесь не хранятся.
