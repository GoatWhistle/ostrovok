# Скриншоты

Скриншоты для README проекта и документации. Каждый снят с реального прогона на демо-данных, а не
собран в редакторе.

| Правило | Почему |
|---|---|
| Окно одной ширины, 1440 px, масштаб 2×: `hero.png` снят в 1440×900 и сохранён в 2880×1800 | Все скриншоты в одном масштабе и сравнимы между собой |
| Имя по содержанию: `hero.png`, `step-3-decision.png` | Файл находится по ссылке из текста без просмотра |
| PNG; больше 1 МБ — сжать без потери читаемости | Репозиторий и страница README открываются быстро |
| Под каждым — подпись `<sub>` о прогоне: какие данные, что видно | Подпись доказывает, что это настоящий результат |
| Без персональных данных и ключей | Скриншоты публикуются вместе с репозиторием |

Скриншоты матрицы экранов (`npm run shots`) сюда не кладутся: они служат проверке, а не показу.
