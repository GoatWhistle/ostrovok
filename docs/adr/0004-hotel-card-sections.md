# 0004. Разделы карточки отеля рядом с картой

Дата:2026-10-28. Статус:реализовано.

Карточка остаётся внутри существующей левой панели. Выбор раздела не меняет выбранный отель, карту или камеру. Фото, название, звёзды, рейтинг и адрес находятся над вкладками. Порядок: «Об отеле», «Рядом», «Удобства», «Платные услуги». Последняя существует только при подтверждённой доплате. На узкой панели прокручивается только ряд вкладок. Клавиши ArrowLeft/ArrowRight, Home/End меняют выбор и фокус; вкладки связаны с панелями через ARIA.

В «Об отеле» первым стоит раскрытие «Описание», затем пожелания/факты, условия проживания, один переход к номерам и источники. Заголовки «Описание» и «Факты об отеле» используют идентичную типографику: размер16px, вес750, line-height1.35 и tracking-tight. Общий Disclosure принимает эти параметры через CSS-переменные, не меняя текст описания. «Факты об отеле» и «Условия проживания» изначально свёрнуты и раскрываются/сворачиваются нажатием заголовка. Их заголовки повторяют типографику «Описание». Время заезда и выезда выделено жирным в двух столбцах. Переход «Номера и цены» расположен ниже условий проживания; его название выделено весом750. Переход «Номера и цены» использует RowButton с постоянным выделением фоном surface-raised, без подложки иконки. Фоновая область расширена на12px в каждую сторону внутри полей карточки. Текст перехода выровнен по левому краю заголовков; значок номера стоит справа рядом с шевроном. Между «Описание» и фактами разделителя нет. Неизвестное время не подставляется. Этажность, количество комнат и история здания раскрываются в «Детали здания». Факты о видах не повторяются, если уже показаны в пожеланиях или общей группе фактов. Внутренние комнаты API сохранены на экране номеров, в том числе при недоступном внешнем каталоге.

В «Рядом» всегда виден полный список мест, отсортированный по расстоянию. Кнопки раскрытия, частичного списка и «Ещё N» нет. Описание расположения перенесено в единое раскрытие «Описание» вкладки «Об отеле». Расстояния остаются метрами/километрами из карточки; они не объявляются рассчитанным пешим маршрутом.

Удобства показываются компактными свёрнутыми категориями. Одновременно открыта одна категория. Внутри ровный список в одну колонку; длинные пояснения раскрываются у конкретного пункта и не раздвигают соседние элементы по умолчанию. Для единственного удобства лишняя категория не создаётся. Резервные удобства из HotelCard/offers также собраны в одно раскрытие целиком. Непривязанные исходные условия находятся в отдельной свёрнутой категории. Данные не сокращаются при большом количестве услуг.

Пояснение связывается с удобством только при точном совпадении нормализованного полного имени в пределах слов. Если совпали несколько имён, выбирается более длинное. Повторяющийся префикс имени не выводится второй раз. Остальные предложения сохраняются. Новые удобства, платность и цены из такого сопоставления не выводятся. Структурированные разделы исходного описания о расположении находятся в About. Общий рекламный текст каталога о номерах не выводится на экране номеров по просьбе пользователя; характеристики, фотографии и цены конкретных номеров сохранены; неизвестные разделы сохраняются в About. Оригинальные данные API не меняются.

Основные строки используют Manrope и основной цвет текста. Категории удобств набраны16px/750, названия услуг13px/650, пояснения14px/450 с увеличенным интервалом и вторичным цветом. Размер пояснений не уменьшен. Категории и услуги сопровождаются локальными Lucide-иконками через общий Icon; неизвестное имя получает значок своей категории. Глобальные токены не менялись. Термин «поставщик» убран из пользовательских подписей; нейтральное «Описание отеля» не приписывает текст площадки напрямую отельеру.

«Все факты и источники» при раскрытии прокручивает только существующую панель к содержимому, оставляя карту на месте. Прокрутка мгновенная и не повторяется при закрытии/обновлении данных. В «Как получен факт» нет отдельной заливки, даты набраны основным шрифтом. Совпадающие источник и уверенность не повторяются; отличающаяся исходная уверенность остаётся видимой. Отсутствующее наблюдение не создаёт пустой строки. Метод, идентификаторы и правила разрешения конфликтов доступны в «Технических подробностях», цитаты и внешняя ссылка остаются доступны.

Контракт SupplierAmenity.free=true подтверждает бесплатность; false не подтверждает платность. Платная вкладка использует текущий факт уровня отеля pets_policy с allowed=true, конечной положительной fee_rub и без ожидающего разрешения конфликта. Сумма форматируется через Intl с плюсом и RUB; период оплаты не угадывается. Нажатие открывает исходный факт. Для иных платных услуг нужен явный источник суммы и периода в API; демонстрационные цены макета не перенесены.

Общий Disclosure поддерживает необязательные iconOnly, expandedTitle, revealOnOpen и контролируемые open/onOpenChange. Существующие неуправляемые вызовы сохраняют поведение. Категории используют штатное CSS-раскрытие без глобального View Transition; клавиатурные действия и reduced motion не получают лишнего движения. Публичные действия HotelDetails/FactDetails и API сервера сохранены.
