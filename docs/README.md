# Документация Factmap

> Factmap подбирает отели Сочи по запросу, написанному в чате обычными словами, и к каждому условию
> показывает факт с источником или пометку «нет данных». Значение факта никогда не приходит от
> языковой модели: у порта `LLMPort` нет метода, который вернул бы значение характеристики, а
> условие с характеристикой не из реестра отбрасывает адаптер (`test_an_invented_characteristic_is_dropped`).
> Здесь описано, как решение устроено, почему именно так, как проверено, где его границы и как его
> запустить.

**Начните здесь, если вы в жюри:** [маршрут для жюри](for-jury.md), пять шагов по локальному стенду
без ключей. Обзор продукта находится в [README проекта](../README.md).
