# Окружение отеля и афиша

Агент выбирает инструменты по пожеланию пользователя. Внешние источники обращаются по координатам отеля и работают без платных ключей. Данные загружаются при запросе, без импорта всей России при запуске. Выбор и оплата языковой модели настраиваются отдельно.

| Инструмент | Источник и результат | Ограничения |
|---|---|---|
| `search_events` | [KudaGo](https://docs.kudago.com/api/): поиск события, затем получение дат и координат площадки | До 20 кандидатов и 12 подходящих сеансов на отель; неполное покрытие городов. Недоступность API возвращается как ошибка источника |
| `read_event_page` | [Event JSON-LD](https://schema.org/Event) на публичной странице: дата, площадка, статус, ссылка | Обрабатывает разметку без исполнения скриптов. Нужны координаты площадки и начало с часовым поясом. Неизвестное окончание остаётся неизвестным |
| `observe_wildlife` | [GBIF](https://www.gbif.org/developer/occurrence): исторические наблюдения выбранного таксона | Только CC0/CC BY, наблюдения людей/приборов, известная погрешность до 1000 м. Событие с учётом погрешности должно помещаться в радиус. Выборка до 100 исходных записей; отсутствие результата остаётся неизвестным |
| `measure_landcover` | [ESA WorldCover 2021 v200](https://esa-worldcover.org/en/data-access): классы покрова вокруг отеля | 13 точек в круге 50–2000 м, метрика при наличии минимум 10. Доля среди точек служит оценкой окружения по карте 2021 года |
| `get_weather` | [MET Norway Locationforecast](https://api.met.no/weatherapi/locationforecast/2.0/documentation): температура, облачность, ветер | Прогноз примерно до 9 дней. Поля возвращаются только при наличии в ответе. За пределами доступных временных отметок результат неизвестен |

Один вызов инструментов окружения исследует максимум четыре отеля. Для афиши задаются начало и конец интервала ISO8601 с явными UTC-смещениями, конец исключён, продолжительность до 31 дня. Радиус до 20 км; для WorldCover до 2 км. Расстояние вычисляется по прямой до площадки. Оно не устанавливает пеший маршрут.

Поиск афиши сначала получает кандидатов KudaGo, затем запрашивает их полные даты и площадки. Временные интервалы проверяются локально на пересечение с поездкой. Если известно только начало, оно должно попадать в поездку; длительность не восстанавливается. Отменённые, отложенные и полностью онлайн-события из Event-разметки исключаются. У KudaGo статус отмены может быть неизвестен. Сведения о событиях не подтверждают наличие билетов.

Для события агент дополнительно проверяет тему пожелания по содержательной цитате. Только проверенная запись даёт положительную метрику. Источники, цитаты и координаты площадок попадают в итоговый факт. Измерения природы и афиши проходят проверку соответствия дате, единицам и смыслу пожелания. Неизмеренные отели не получают отрицательных фактов.

Наблюдение животного в прошлом не обещает встречу во время поездки. Карта WorldCover описывает земной покров в 2021 году: выборка не измеряет точную площадь леса и не подтверждает вид из номера. Известная погрешность GBIF учитывается консервативно; записи без погрешности исключаются.

MET Norway используется и для агента, и для `/api/v1/weather`. HTTP-форма сохранена, поле `source` указывает поставщика. Существующий контракт времени карты сохранён: дата и час интерпретируются в Europe/Moscow. Символы погоды MET преобразуются в поддерживаемые WMO-коды; неподдерживаемый символ даёт недоступность. Модельные отметки подбираются с допуском 30 минут, без экстраполяции за горизонт прогноза.

Для MET нужен идентифицирующий `PUBLIC_DATA_USER_AGENT` с настоящим контактом. По умолчанию указан репозиторий проекта. При развёртывании укажите свой контакт. Ответы кешируются до `Expires`, просроченные проверяются через `If-Modified-Since`; после 429 повторные запросы блокируются на `Retry-After`. [Условия MET](https://api.met.no/doc/TermsOfService).

Ссылки на поставщиков и CC BY 4.0 доступны в источниках карты. Для WorldCover указаны год, проект и обработка Copernicus Sentinel; конкретные источники также сохраняются в фактах. Страницы Event читаются существующим ограниченным HTTP-ридером: только публичные адреса, стандартные порты, до 1 МБ и четырёх переходов. Соблюдение правил конкретного сайта остаётся обязательным; разметка Schema.org сама по себе не предоставляет лицензию на содержание.

Состав инструментов подключён в коде. Активация в уже работающем стенде требует отдельного обновления процессов. При реализации модель не вызывалась, рабочий стенд не перезапускался.
