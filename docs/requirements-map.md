# Карта требований

Каждая строка — требование ТЗ из `brief/requirements.md`: чем закрыто,
чем проверено, где граница. Из девяти обязательных требований восемь проверены на стенде, одно
закрыто частично. Из пяти дополнительных четыре проверены на стенде, один закрыт
частично.

**Читайте, если** вы сверяете решение с постановкой пункт за пунктом · **Связано:**
[для жюри](for-jury.md) · [доказательства](evidence.md) · [ограничения](limitations.md)

---

## Как читать статус?

| Статус | Что значит |
|---|---|
| **стенд** | Проверено на запущенном стенде; что именно и когда, указано в колонке проверки |
| **код** | Есть код и тесты, на запущенном стенде целиком не проверялось |
| **частично** | Закрыта часть требования; граница названа в колонке «Границы» |
| **нет** | Не реализовано; что есть вместо, в той же колонке |

## Обязательные требования

| # | Требование | Чем закрыто | Проверка | Статус | Границы |
|---|---|---|---|---|---|
| R1 | Сбор характеристик, хотя бы одна по геоданным | Цикл пожелания сам выбирает инструменты (`application/agent/wish_loop.py`); расчёт по DEM Copernicus GLO-30 и footprint'ам OSM в `adapters/geo/window_views.py`, `terrain_measurements.py`, `view_assessment.py` | В базе стенда 758 фактов `window_visibility@1`, 6989 `noise_level@1`, 890 `distance_to_sea@1` | **стенд** | Высота известна не у всех зданий, остальные оценены по этажности |
| R2 | Диалог с отельером: вопрос, свободный ответ, раскладка по полям | `use_cases/hotelier_questions.py`, `use_cases/answer_question.py` | 2026-10-27: вопрос `q_w31482145_pets_policy`, ответ «с собаками до 10 кг, доплата 2500 рублей» дал факт `allowed=true, max_weight_kg=10, fee_rub=2500`, `source_type=hotelier`, `confidence=1.0`, цитата в объяснении | **стенд** | Вход не проверяется, [ограничения](limitations.md) |
| R3 | Источник, уверенность, дата; противоречия замечены и разобраны | Колонки `source_type`, `source_url`, `method`, `confidence`, `computed_at`, `valid_until`, `evidence` в `facts`; таблица `conflicts`, `domain/services/conflict_resolver.py`, `application/fact_versions.py` | Поля видны в карточке и в ответе `/facts/{id}/correct`; разрешение конфликтов покрыто юнит- и PostgreSQL-тестами. 2026-10-28 на отдельном стенде: у всех 9 348 фактов Сочи есть доказательство вида `dataset` с именем экстракта OSM и тайлов Copernicus, у 839 фактов о высоте — ссылка на объект в openstreetmap.org, которую можно открыть | **стенд** | 2026-10-27: исправление факта `room_capacity` отельером (4 → 2) записало конфликт `resolved_by_rule` с правилом `hotelier > fresh_computed > osm_tag > stale_computed`; карточка отдаёт оба значения и показывает их |
| R4 | Расширяемость: характеристику можно добавить описанием | `characteristics/*.yaml` через `adapters/registry/yaml_loader.py`; плюс динамические пожелания агента без реестра | 9 файлов в `characteristics/`, `GET /api/v1/characteristics` отдаёт те же 9; офлайн-разбор читает фразы из реестра | **стенд** | Новая характеристика по геоданным требует инструмента, одним YAML закрываются текстовые и отельерские |
| R5 | Поиск по запросу своими словами | Чат: `use_cases/chat.py` → `use_cases/search_hotels.py` → агент → проверка | 2026-10-27, живой стенд: Казань 18 с, Кострома 24 с, Петербург 22 с, Москва 12 с; [прогоны](evidence.md) | **стенд** | Без ключей работает офлайн-разбор, он не понимает объекты рядом |
| R6 | Один выбранный регион, глубина важнее охвата | Сочи — заявленный регион с предрасчётом (фасады, шум, пеший маршрут, закат); Россия — расширение по запросу, 33 233 отеля | 2026-10-28: [замер](evidence.md#какой-регион-заявлен-и-чем-подкреплено-28-октября-2026) — контуры зданий у 93 % отелей страны, этажность у 10 %; живой запрос непуст в шести городах за 15–50 с | **стенд** | Вне Сочи нет предрасчитанных фасадов, шума и заката |
| R7 | Запуск по инструкции из README | [`docs/running.md`](running.md), `make up && make seed && make precompute` | 2026-10-27: [прогон из чистого клона](evidence.md#запуск-из-чистого-клона-27-октября-2026); четыре отказа инструкции найдены и исправлены | **стенд** | — |
| R8 | Без многочасовой загрузки: демо-данные в репозитории | `data/seed` 71 МБ в репозитории | 2026-10-27: клон 80 с, `make up` 30 с, `make seed` 33 с, `make precompute` 8 с, первый ответ 1 с — **около двух с половиной минут** | **стенд** | Слой образов Docker был тёплым; полностью холодная сборка дольше |
| R9 | Ключ LLM описан, есть `.env.example` | `README.md`, `.env.example` | Оба файла в репозитории, `LLM_API_KEY` описан в обоих | **стенд** | — |

| O2 | Сравнение отелей | `POST /api/v1/compare`, `use_cases/compare_hotels.py`, `pages/compare/` | 2026-10-27: запрос с двумя идентификаторами вернул 200 с геометрией видимости по каждому | **стенд** | Сравниваются собранные факты, не цены |

## Какие допущения приняты без ответа организаторов?

| Неясность | Наше допущение | Что изменится, если допущение неверно |
|---|---|---|
| Критерии и веса жюри | Приоритет по порядку ТЗ: пять основных задач раньше пяти дополнительных | Порядок работ поменяется под веса |
| Какой регион заявлять | Сочи как глубина, Россия как проверяемое расширение | Понадобится замер покрытия по стране |
| Нужен ли вход | Одно рабочее пространство без регистрации | Вход путешественника и отельера, права отельера на свой отель |
