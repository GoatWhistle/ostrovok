## Как оценивается каждое утверждение?

У каждого утверждения один из семи статусов. Когда подходят два, ставится более низкий.

| Статус | Что значит |
|---|---|
| **Измерено** | Число выдаёт команда в этом репозитории; команда и размер выборки опубликованы рядом |
| **Закреплено** | Машинная проверка падает, когда свойство перестаёт выполняться; проверка названа и входит в обязательный прогон |
| **Проверено вручную** | Проверено выполнением на конкретных названных входах, без общего замера |
| **Наблюдалось** | Видели в живом прогоне, возможно один раз; не обобщается |
| **Из источника** | Число или правило третьей стороны со ссылкой; здесь не перемерялось |
| **Допущение, не результат** | Рассуждение без замера; помечено, чтобы ему не поверили случайно |
| **Неверно, и это сказано** | Свойство, которого читатель мог бы ожидать, но которого у системы нет |

Статусы упорядочены от сильного к слабому. «Код есть» — не статус: код без теста и без прогона на
стенде доказывает только то, что код написан.

## Отвечает ли поиск на набор из 22 запросов?

**Гипотеза:** стенд с живой моделью и PostGIS отвечает на каждый запрос набора без ошибки, а там,
где подтверждающих данных нет, возвращает пустую выдачу вместо ложного совпадения.

Flash, одна попытка на запрос. Набор и ожидаемое поведение каждого запроса записаны до прогона.

## Сколько данных в загруженном срезе?

**Гипотеза:** срез Сочи содержит все отели и здания OSM внутри выбранного прямоугольника, этого
хватает для поиска по всему городу.

**Чем измерено:** `make build-seed` вырезает срез из экстракта OSM и тайлов DEM, печатает число
объектов каждого слоя и пишет их в `data/seed/sochi/meta.json`; `make seed` загружает тот же срез
в PostGIS.

**На какой выборке:** один экстракт Geofabrik `south-fed-district-latest.osm.pbf`, срез собран
2026-10-25, прямоугольник 39,55–40,0° в. д., 43,35–43,75° с. ш.:

| Слой | Объектов |
|---|---:|
| Отели | 854 |
| Здания | 105 981 |
| Объекты POI | 26 519 |
| Рёбра пешеходного графа | 34 028 |
| Источники шума | 2 015 |
| Пляжи | 115 |
| Линии берега | 78 |

**Чего эта выборка не показывает:** сколько отелей Сочи в OSM нет вовсе и насколько полны теги
найденных объектов. Высота из OSM известна у малой части зданий, подробности в
[ограничениях](limitations.md#высоты-зданий-и-шум-приблизительны).
