# Презентация Factmap

Презентация решения в двух форматах с одинаковой структурой из 10 слайдов: проблема, разбор запроса
в чате, факты об отеле на карте, данные, поиск в интернете, карточка отеля, архитектура, пайплайн
агента.

| Файл | Что внутри | Когда открывать |
| --- | --- | --- |
| [presentation.html](presentation.html) | Камера летит над 3D-городом, собранным из наших данных, факты об отеле появляются прямо на карте, чат и схемы анимированы | Основной вариант, смотреть лучше его |
| [presentation.pdf](presentation.pdf) | Те же слайды статичными страницами, без анимаций и 3D-города | Если браузер недоступен или нужно распечатать |

## Как открыть HTML

Скачайте `presentation.html` и откройте в Chrome. Это один самодостаточный файл: шрифты, фото, данные
города и 3D-движок лежат внутри, поэтому сеть, сервер и запущенный стенд не нужны.

| Клавиша | Действие |
| --- | --- |
| `→`, пробел, клик по правой части экрана | следующий слайд |
| `←`, клик по левой части экрана | предыдущий слайд |
| `F` | полный экран |
| `R` | проиграть анимацию слайда заново |

Чтобы открыть нужный слайд сразу, допишите к адресу его номер, например `presentation.html#5`.
