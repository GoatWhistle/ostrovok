# Презентация Factmap

Презентация решения для защиты в трёх форматах.

| Файл | Формат | Когда открывать |
|---|---|---|
| [index.html](index.html) | HTML | Основной вариант. Живая карта, анимации и демонстрация поиска. Откройте в браузере |
| [factmap.pdf](factmap.pdf) | PDF | Статичная копия, если браузер недоступен. Анимаций и живой карты в ней нет, поэтому её мы не советуем |
| [factmap.pptx](factmap.pptx) | PowerPoint | Та же статичная копия для PowerPoint и Keynote |

HTML-презентация работает офлайн: все шрифты и картинки лежат рядом с файлом.
