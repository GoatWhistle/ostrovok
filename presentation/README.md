# Презентация Factmap

Презентация решения для защиты в двух форматах.

| Файл | Формат | Когда открывать |
| --- | --- | --- |
| [index.html](index.html) | HTML | Основной вариант. Камера летит над 3D-городом, собранным из наших данных, и показывает факты об отеле. Откройте в Chrome |
| [factmap.pdf](factmap.pdf) | PDF | Статичная версия той же структуры, если браузер недоступен. Анимаций и 3D-города в ней нет |

HTML-презентация — один файл: шрифты, фото и данные города лежат внутри, сеть и стенд не нужны.

## Управление

| Клавиша | Действие |
| --- | --- |
| `→`, пробел, клик по правой части | следующий слайд |
| `←`, клик по левой части | предыдущий слайд |
| `F` | полный экран |
| `R` | проиграть анимацию слайда заново |
| `#5` в адресе | открыть пятый слайд |

## Сборка

Нужен Node.js 22.18 или новее.

```sh
cd presentation
npm ci
npm run dev
npm run build
```

`npm run dev` открывает презентацию на <http://localhost:4180>. `npm run build` проверяет типы и пишет
`index.html` одним файлом. Город построен из выгрузки PostGIS стенда (`src/data/city.json`): контуры и
высоты зданий, дороги, зелень, вода, береговая линия, маршрут до моря и источники шума.

PDF собирается из `pdf/index.html`: `cd frontend && node ../presentation/pdf/render.mjs`.
