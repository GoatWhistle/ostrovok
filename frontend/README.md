# Hotel Agent: фронтенд

React, TypeScript и Vite. Поиск отелей, карта окружения, источники фактов,
сравнение и ответы отельера используют [контракт API](../docs/api/openapi.yaml).
Интерфейс доступен на русском и английском, в светлой и тёмной темах.

## Запуск

Нужен Node.js 22.18 или новее. Из каталога `frontend/`:

```sh
npm ci
API_URL=http://127.0.0.1:8000 npm run dev
```

`API_URL` задаёт адрес бэкенда для Vite proxy. Клиент обращается к `/api/v1`.
Для карты задайте `MAP_ASSET_URL` — адрес Nginx из Compose, обслуживающего `/maps/`
с локальными PMTiles, шрифтами и спрайтами. Например, при фронтенде Compose на порту 8080:
`API_URL=http://127.0.0.1:8000 MAP_ASSET_URL=http://127.0.0.1:8080 npm run dev`.
Без `MAP_ASSET_URL` запросы ресурсов идут на `API_URL`; сервер должен обслуживать `/maps/`.
В production reverse proxy должен направлять этот префикс на бэкенд.
Никакие платные ключи для интерфейса и MapLibre не нужны.

## Состояние интеграции на 25 октября 2026

В базовом бэкенде `adb6014` реализованы только `/health` и `/characteristics`.
Поиск, регионы, отели, сцены, сравнение и мутации подготовлены по OpenAPI;
до реализации серверных методов интерфейс показывает ошибку и повтор запроса.
Демонстрационных отелей в приложении нет. Ответы в `tests/contract/` используются
только браузерными тестами и не включаются в приложение.

Карта рисует геометрию из API. Объём здания требует `height_m`; неизвестная высота
остаётся контуром. Terrain и внешняя картографическая подложка не подключены.
Фасады и маршруты подсвечиваются по геометриям свойства. Карта не подтверждает
видимость из окна и не вычисляет географические факты самостоятельно.

## Проверки и обновление типов

```sh
API_SCHEMA_URL=../docs/api/openapi.yaml npm run api:types
npm run verify
npx playwright install chromium
E2E_BASE_URL=http://127.0.0.1:5173 npm run e2e
```

Для e2e должны работать Vite и бэкенд: health и каталог проверяются без подмены.
Будущие методы проверяются отдельными контрактными ответами в тестах.
`npm run build` создаёт `dist/`; `npm run preview` показывает сборку локально.
