# Factmap: фронтенд

Интерфейс Factmap: чат с поиском отелей, объёмная карта города с проверкой каждого условия,
карточка отеля с номерами, сравнение отелей и кабинет отельера. Русский и английский языки,
светлая и тёмная темы, раскладка для телефона.

Стек: React 19, TypeScript, Vite, MapLibre GL, TanStack Query, CSS Modules. Типы API
генерируются из [контракта OpenAPI](../docs/api/openapi.yaml).

## Запуск

Проще всего поднять весь стенд из корня репозитория: `make up`, интерфейс откроется на
<http://localhost:8080>.

Для разработки нужен Node.js 22.18 или новее. Из каталога `frontend/`:

```sh
npm ci
API_URL=http://127.0.0.1:8000 MAP_ASSET_URL=http://127.0.0.1:8080 npm run dev
```

`API_URL` — адрес бэкенда для прокси Vite, клиент обращается к `/api/v1`. `MAP_ASSET_URL` —
адрес Nginx из Compose, который отдаёт `/maps/` с локальными PMTiles, шрифтами и спрайтами.
Платные ключи для карты не нужны.

## Что внутри

- `src/app` — провайдеры, роутер, корневой макет;
- `src/pages` — экраны: главная, рабочее пространство, сравнение, кабинет отельера;
- `src/features` — сценарии: чат, поиск, карта, карточка отеля, сравнение, факты;
- `src/entities` — данные и их отображение, запросы TanStack Query;
- `src/shared` — API-клиент, UI-примитивы, i18n, тема, токены, движок карты (`shared/geo`).

Карта рисует город из векторных тайлов бэкенда: рельеф, здания со скатными крышами и окнами,
деревья, освещение по положению солнца, ночной режим.

## Проверки

```sh
npm run verify
npx playwright install chromium
E2E_BASE_URL=http://127.0.0.1:5173 npm run e2e
```

`verify` запускает правила репозитория, проверку типов, линтер, юнит-тесты и сборку.
После изменения API: `API_SCHEMA_URL=../docs/api/openapi.yaml npm run api:types`.
