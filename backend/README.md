# Factmap: бэкенд

API Factmap на FastAPI и PostGIS. Разбирает запрос из чата на условия, ищет кандидатов в регионе,
проверяет каждое условие по фактам с источником (OSM, рельеф, данные поставщика, ответы отельера)
и отдаёт векторные тайлы и рельеф для карты. Языковая модель только раскладывает запрос на условия
и пишет ответ: значение характеристики она не выдаёт.

Устройство по слоям: `src/hotel_agent/` — домен, сценарии, адаптеры (БД, LLM, внешние источники),
HTTP-интерфейс. Миграции в `migrations/`, тесты в `tests/`.

## Запуск

Весь стенд из корня репозитория:

```sh
cp .env.example .env
make up
make seed
```

API отвечает на <http://localhost:8000>, проверка: `GET /api/v1/health`. Без ключа LLM поиск
работает на офлайн-разборе (`LLM_PROVIDER=fake`). Живая модель: `LLM_PROVIDER=openai_compat` и
переменные `LLM_*` в `.env`.

Локально с перезагрузкой против базы из Compose: `make api`.

## Проверки

```sh
cd backend
uv run ruff check .
uv run mypy .
uv run pytest tests/unit
uv run pytest tests/integration
```

Интеграционные тесты создают временные базы в кластере PostGIS стенда.
