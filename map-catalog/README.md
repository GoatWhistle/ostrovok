# Каталог классов карты

64 класса четырёх ярусов: земля, объёмы, предметы и POI. Новый класс добавляется YAML-файлом, имя которого совпадает с `key`. Правила `match` объединены через OR. Побеждает наибольший `priority`, при равенстве — ключ по алфавиту. Каждый ярус имеет ровно один класс без правил — значение по умолчанию.

`style.fill` — имя токена, значения палитры выбирает клиент. До выбора стиля палитры находятся только в HTML-примерах. `props` хранит модель и параметры плотности; визуальные предметы не становятся фактами об отеле.

Для неопределённого `building=yes` порядок вывода: связь с отелем, известный POI внутри контура, landuse центроида, площадь и этажность, значение по умолчанию. Конкретный тег building имеет приоритет над выводом. Поле class_source хранит шаг, на котором принято решение.

`GET /api/v1/map/catalog` отдаёт каталог. Переклассификация происходит при `make import-map-layers`, а не при запросе тайла. `MAP_CATALOG_DIR` позволяет сменить каталог при запуске API.
