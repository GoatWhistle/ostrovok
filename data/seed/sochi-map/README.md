# Дополнительные слои Сочи

`layers.geojson.gz` — подготовленный срез OSM в bbox 39.55,43.35,40,43.75. Источник: Overpass, дата базы 2026-10-26T13:33:39Z. Лицензия: © OpenStreetMap contributors, ODbL. Манифест содержит число импортированных объектов и проверку стороны моря по Copernicus GLO-30.

Импорт без сети после основных слоёв Сочи и миграций:

```bash
DATABASE_URL=postgresql://hotel:hotel@localhost:5432/hotel \
  uv run --directory backend python scripts/import_map_layers.py --prepared
```

Реальные настройки подключения подставляются из окружения. Импорт обновляет таблицы landcover, water_areas и trees, классы существующих зданий и дорог. Повторный запуск обновляет записи по OSM ID. Старые объекты, исчезнувшие из новой выгрузки, автоматически не удаляются.

`make fetch-map-layers` обновляет исходную выгрузку отдельно. `make import-map-layers` использует её при наличии, иначе подготовленный срез. Сетевых запросов при импорте нет. Классификация определяется YAML в `map-catalog/`.
