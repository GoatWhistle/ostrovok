# Текстура главного корпуса «Жемчужины»

Готовый материал и GLB для здания `w51847429` из среза Сочи. Создано 25 октября 2026 года.
Это визуальная реконструкция: фасады и оборудование крыши сгенерированы по референсам.

| Файл | Содержимое |
|---|---|
| `albedo-atlas-v1.png` | RGB-атлас 1254 × 1254: два длинных фасада, торец и крыша |
| `atlas-layout.json` | Границы панелей в пикселях, с исключением неба над фасадами |
| `building.glb` | Объём по контуру OSM, UV, нормали, материал и встроенная текстура |
| `building.json` | Начало координат WGS84, размеры, методы и ограничения |

## Геометрия и материал

Контур взят из `data/seed/sochi/buildings.geojson`, объект `w51847429`.
В теге `building:levels` указано 17. Высота 51 м получена умножением на допущение 3 м на этаж.
Длина около 148,5 м, ширина около 16,9 м вычислены из контура в локальной метрической проекции.
Это оценки по исходным данным, независимого обмера нет. Координаты GLB: X на восток,
Y вверх, Z на юг; единица измерения — метр. Геопривязка сохранена в `extras` узла GLB.

В атласе есть освещение углублений и небольшие тени. Это материал base color с запечёнными
визуальными деталями, полноценные normal/roughness-карты не созданы. Балконы и оборудование
не выступают из геометрии. Число окон и положение рядов относительно реальных этажей не проверены.
Линейная фильтрация без mipmaps исключает смешивание соседних панелей атласа.

Сгенерированные окна, балконы и вентиляция не подтверждают сведения о номерах или видимости.
